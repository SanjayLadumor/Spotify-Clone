# Spotify Clone 🎵

A modern and responsive Spotify-inspired music player UI built to recreate the look and feel of the original Spotify web experience. This project focuses on frontend design, smooth layouts, and interactive music player components.

---

## 🚀 Live Demo

Check out the repository here:  
<br>
https://sanjayladumor.github.io/Spotify-Clone/

---

## ✨ Features

- 🎧 Spotify-inspired modern UI
- 📱 Fully responsive layout
- 🎵 Interactive music player interface
- ⏯️ Play / Pause controls
- 📂 Playlist and album sections
- 🌙 Clean dark theme design
- ⚡ Smooth animations and transitions

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/SanjayLadumor/Spotify-Clone.git
```

Navigate to the project folder:

```bash
cd Spotify-Clone
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
